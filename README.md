## Обзор системы

Система предоставляет комплексное решение для управления учебным процессом в образовательном учреждении, включая:
- Личные кабинеты для студентов, преподавателей, заведующих отделением, методистов и социальных педагогов
- Мониторинг успеваемости и посещаемости
- Управление расписанием занятий
- Работу с документами и заявлениями
- Социальное сопровождение обучающихся
- Формирование социальных портретов учебных групп
- Аналитику и отчетность

---

## Функциональные модули

### Модуль студента

#### Основные возможности:
- Панель управления - обзор успеваемости и посещаемости
- Успеваемость - просмотр оценок по семестрам и предметам
- Посещаемость - мониторинг присутствия на занятиях
- Расписание - просмотр учебного расписания
- Документы - управление личными документами
- Личный кабинет - редактирование персональных данных

#### Детализация функционала:

##### Успеваемость
- Семестровый просмотр - оценки по семестрам
- Предметный анализ - детальная информация по каждому предмету
- Аналитика - графики и статистика успеваемости
- Детали оценок - просмотр комментариев преподавателей, истории изменений

##### Посещаемость
- Статусы посещений: 
  - "п" - Присутствовал
  - "у" - Уважительная причина  
  - "н" - Отсутствовал
- Визуализация - цветовые индикаторы статусов
- Статистика - процент посещаемости по предметам
- Детальная информация - причины пропусков, комментарии преподавателей

##### Документы
- Загрузка документов - личные файлы и заявления
- Категоризация - сортировка по типам документов
- Скачивание - доступ к загруженным материалам
- Управление доступом - настройки видимости для преподавателей

---

### Модуль преподавателя

#### Основные возможности:
- Панель управления - обзор преподаваемых предметов и групп
- Выставление оценок - система оценивания студентов
- Управление посещаемостью - отметка присутствия/отсутствия
- Аналитика групп - статистика по успеваемости и посещаемости
- Расписание - просмотр преподавательского расписания
- Разделение групп на подгруппы - автоматическое и ручное распределение
- Кураторство - управление закрепленными группами
- Социальный портрет группы - формирование социального профиля
- Личный кабинет - редактирование персональных данных

#### Детализация функционала:

##### Управление оценками
- Система оценивания - баллы от 1 до 5
- Типы работ - различные виды учебной деятельности
- Комментарии - обратная связь для студентов
- Автоматический расчет среднего балла и процента посещаемости
- Итоговая аттестация

##### Управление посещаемостью
- Быстрая отметка - массовое заполнение посещаемости
- Учет причин пропусков - отметка уважительных причин
- Статистика групп - аналитика посещаемости по группам

##### Управление группами
- Просмотр закрепленных групп
- Разделение на подгруппы - автоматическое по алфавиту или ручное
- Фильтрация по семестрам и курсам

##### Кураторство
- Список кураторских групп с прогресс-барами посещаемости и успеваемости
- Просмотр и смена старост(ы) группы
- Дополнение информации о студентах (адрес, основа обучения, соц.категории)

##### Социальный портрет
- Многошаговый мастер заполнения
- Распределение студентов по социальным категориям

---

### Модуль отдела расписания

#### Общие возможности для студентов и преподавателей:
- Недельное расписание - просмотр по неделям
- Типы недель - верхняя/нижняя неделя
- Детали занятий - время, аудитория, тип занятия

#### Расписание для студентов:
- Групповое расписание - занятия своей группы
- Замена занятий 

#### Расписание для преподавателей:
- Преподавательское расписание - все занятия преподавателя
- Нагрузка по группам - распределение по учебным группам
- Замена занятий 
- График работы

---

### Модуль методиста

#### Управление расписанием:
- Формирование расписания для учебных групп
- Редактирование текущего расписания выбранной группы
- Просмотр расписания учебных групп
- Экспорт расписания выбранной группы в формате XLSX

#### Управление изменениями:
- Добавление изменений в расписание
- Добавление новой пары как изменение в расписании
- Просмотр изменений в расписании по датам
- Экспорт документа с изменениями в формате DOCX

#### Настройка преподавателей:
- Привязка аудитории к преподавателю
- Добавление примечаний составления расписания к конкретному преподавателю

#### Типы пар и недель:
- Верхняя и нижняя недели
- Общие пары (для обеих недель)
- Разделение на подгруппы (1 и 2)
- Отображение верхней и нижней недель в одной ячейке

#### Интерфейс редактирования:
- Поиск и выбор преподавателей с отображением примечаний
- Фильтрация предметов по выбранному преподавателю
- Автоматическая сортировка аудиторий (сначала привязанная к преподавателю)
- Поиск аудиторий
- Выбор подгруппы (общая, подгруппа 1, подгруппа 2)
- Выбор недель для пары (верхняя/нижняя/обе)
- Удаление и скрытие занятий

---

### Модуль социального педагога

#### Основные возможности:
- Панель управления - обзор всех групп колледжа
- Мониторинг успеваемости - просмотр в режиме "только чтение"
- Мониторинг посещаемости - аналитика пропусков
- Социальные портреты - анализ групп по социальным категориям
- Статистика по курсам - сводные показатели
- Формирование отчетов - экспорт в Word
- Редактирование данных студентов - внесение и корректировка информации о сиротах и инвалидах

#### Детализация функционала:

##### Группы
- Просмотр всех групп колледжа с расширенной фильтрацией
- Отображение количества социальных категорий в группе
- Данные старосты и куратора

##### Детали группы
- Список студентов с ФИО, социальными категориями, основами обучения, адресами, датами рождения и телефонами
- Фильтрация студентов по выбранным социальным категориям (мультивыбор)
- Разворачивание/сворачивание детальной информации о студенте

##### Статистика
- Общая статистика по группам (количество групп и студентов)
- Статистика по курсам (средний балл и процент посещаемости)
- Статистика по социальным категориям

##### Отчеты
- Формирование отчетов по детям-сиротам и детям-инвалидам
- Экспорт в формат Word
- История созданных отчетов с фильтрацией, поиском сортировкой

##### Редактирование данных о сиротах и инвалидах
- Интерактивные таблицы с возможностью редактирования ячеек
- Прикрепление фотографий справок
- Изменение статусов инвалидности и видов ограничений


## Установка и запуск

### Предварительные требования
- Node.js 16+
- npm или yarn
- Современный браузер с поддержкой ES6+

### Установка
```bash
# Клонирование репозитория
git clone <repository-url>
cd scollege-diary-frontend

# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка для production
npm run build
```

## Технологии

### Frontend
- **React 18** - основной фреймворк
- **TypeScript** - типизация
- **React Router** - маршрутизация
- **Context API** - управление состоянием
- **CSS3** - стилизация
- **Recharts** - построение графиков

### Backend 
- **Spring Boot** - основной фреймворк
- **Java 17+** - язык программирования
- **PostgreSQL** - база данных
- **JWT** - аутентификация
